This directory is intentionally empty.

Agent A5 owns the entire frontend (React + Vite + Tailwind, dark mode
default). Nothing here was scaffolded on purpose — set up Vite from
scratch so you get a clean, current template rather than one baked by
Agent A1.

Expectations from the shared scaffold (see backend/gramvault/main.py):
  - Production builds should output to frontend/dist/, which
    gramvault.main mounts as static files when it exists (TODO(A5) marks
    the exact spot).
  - Dev server is expected on the Vite default port (5173); main.py's CORS
    middleware already allows http://localhost:5173 for local development.
  - Talk to the backend via the routers in backend/gramvault/api/ — see
    routes_library.py, routes_enrich.py, routes_chat.py, routes_export.py
    for the request/response contracts (Pydantic models mirror what the
    JSON API returns).
